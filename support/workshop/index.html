Backing Up and Moving Your Data

Since Workshop stores everything on your device and has no account or server, backups are entirely in your hands. There are two ways to do it, both from Settings:

Back Up to iCloud

Tap "Back Up to iCloud" to save a backup file to your own iCloud Drive, in a folder private to Workshop. This is the easiest way to move data to a new device — just restore from the same option after installing Workshop there.

Export / Import Backup

"Export Backup" creates a local backup file and hands it to iOS's share sheet, so you can save it to Files, send it by AirDrop, email it to yourself, or store it anywhere else you'd like. "Import Backup" reads a backup file back into the app. Useful for backups outside iCloud, or moving data between accounts.

Siri Shortcuts

Workshop supports two Siri shortcuts, available once you've created at least one project:

  • Add a note to a specific project — say something like "Add a note to [project name] in Workshop," and Siri will ask what you'd like the note to say.
  • Mark maintenance done — say "Mark [task] as done in Workshop," and Siri will walk you through any fields the task needs (mileage, cost, notes) by voice.

If Siri doesn't recognize a project or task by name, open Workshop once so it can refresh its index, then try again.

Calendar Sync

Any Date field can optionally sync to a calendar of your choosing — enable it from the field's settings. Workshop creates a single event (just a title and date) and keeps it updated as the field changes. Turning sync off, or deleting the field or project, removes the event automatically.

Vehicle & Maintenance Tracking

Add a vehicle from the Garage section, then use "Decode VIN" to auto-fill year, make, and model. Maintenance tasks can be tracked by mileage or date — mark one done and Workshop schedules its next occurrence automatically if it's set up as recurring.

If VIN decoding doesn't return results, double check the VIN was entered correctly — Workshop relies on the NHTSA's free public lookup service, which occasionally doesn't have data for older or unusual vehicles.
